## ⚠️ Repository Size Warning

**Please note:** This repository contains a massive collection of high-quality images. The total size is currently estimated to be **around 1.5 to 2+ GB**.

Downloading the `.zip` file or cloning the entire repository may take a while and consume a significant amount of bandwidth.

> ⚠️ **Important Note:** Due to the large number of high-quality wallpapers, please be mindful of your data usage before cloning or downloading the entire repository!

> **💡 Pro Tip:** If you want to clone this repository, it is highly recommended to use a shallow clone to save time and storage:
>
> ```bash
> git clone --depth 1 [https://github.com/hnaseri77/wallpapers.git](https://github.com/hnaseri77/wallpapers.git)
> ```
